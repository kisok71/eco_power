# ⚡ PC PowerSaver Pro (PC 절전 & 전원 관리 프로그램)

Windows PC 환경에 최적화된 **스마트 전원 관리 및 절전 모드 제어 프로그램**입니다.
별도의 런타임이나 프로그램 설치 없이, Windows 내장 PowerShell 및 배치 파일을 사용하여 1-클릭으로 실행할 수 있습니다.

## 1. 개요 및 특징

- **무설치 원클릭 실행**: Python이나 Node.js 같은 별도 런타임 설치 없이 Windows 기본 파워쉘과 WPF 엔진으로 구동됩니다.
- **다양한 전원 동작 지원**: 단순 종료뿐만 아니라 **절전 모드(Sleep)**, **최대 절전(Hibernate)**, **화면만 끄기(Screen Off)**, **다시 시작(Restart)**을 모두 지원합니다.
- **스마트 부재 감지**: 키보드/마우스의 미입력 시간을 Win32 API 레벨에서 정확히 추적하여 컴포넌트 동작을 자동화합니다.
- **모던 다크 테마**: 세련된 다크 글래스모피즘(Dark Glassmorphism) 인터페이스로 눈의 피로를 최소화합니다.

## 2. 프로그램 실행 방법

### ① 데스크톱 GUI 프로그램 실행
프로그램이 위치한 폴더(`c:\Users\jkiso\Documents\test`)에서 **`Run_PowerSaver.bat`** 파일에 마우스 우클릭 후 **더블 클릭**합니다.
- 파워쉘 실행 정책 우회 옵션(`-ExecutionPolicy Bypass`)이 내장되어 있어 추가 설정 없이 1초 만에 실행됩니다.

### ② 웹 대시보드 실행
**`index.html`** 파일을 더블 클릭하여 크롬(Chrome), 엣지(Edge) 등 웹 브라우저에서 실행하면 시각적인 전원 관리 대시보드와 전기요금 절감 계산기를 사용할 수 있습니다.

## 3. 데스크톱 GUI 메뉴 상세 설명

### ⏱️ 타이머 설정 (Countdown Timer)
지정한 시간이 지나면 선택한 전원 동작을 자동으로 실행하는 카운트다운 타이머 기능입니다.

- **빠른 시간 선택**: `15분`, `30분`, `1시간`, `2시간` 버튼을 누르면 즉시 설정됩니다.
- **사용자 지정 (분)**: 슬라이더를 움직이거나 우측 입력창에 1분~300분 사이의 숫자를 직접 입력합니다.
- **수행할 동작 선택**:
  - `🌙 절전 모드 (Sleep)`: RAM에 상태를 보존하고 최소 전력 모드로 진입 (1초 만에 복구 가능)
  - `💤 최대 절전 모드 (Hibernate)`: 작업 내용을 SSD/HDD에 저장 후 완전 전원 차단
  - `🖥️ 화면만 끄기 (Screen Off)`: 본체 작업(다운로드/음악 등)은 유지하고 모니터만 OFF
  - `🔌 PC 완전 종료 (Shutdown)`: 실행 중인 앱을 안전하게 정리 후 컴퓨터 종료
  - `🔄 PC 다시 시작 (Restart)`: 컴퓨터 재부팅
- **실행 방법**: `▶️ 타이머 시작` 버튼을 클릭하면 실시간 남은 시각과 프로그레스 바가 표시됩니다. 중간에 취소하려면 `⏹️ 취소` 버튼을 누르세요.

---

### 💤 부재 감지 절전 (Idle Auto-Sleep)
사용자가 컴퓨터를 조작하지 않는 시간(키보드/마우스 입력 없음)을 감지하여 자동으로 절전 상태로 만드는 기능입니다.

- **부재 감지 기능 활성화**: 체크박스를 체크하면 부재 감지 모니터링이 시작됩니다.
- **부재 임계 시간 (분)**: 1분~120분 사이로 설정합니다. (예: 10분 설정 시, 10분 동안 마우스/키보드 움직임이 없으면 발동)
- **현재 부재 시간 표시**: 하단 텍스트 창에 현재 컴퓨터가 비워진 시간이 초 단위로 실시간 업로드됩니다. 마우스를 1픽셀이라도 움직이면 0초로 초기화됩니다.

---

### ⏰ 예약 시간 절전 (Scheduled Power Control)
매일 특정 시각에 맞춰 자동으로 PC를 종료하거나 절전 모드로 전환합니다. **최대 2개의 독립된 예약(예약 1, 예약 2)**을 동시에 설정할 수 있습니다.

- **📌 예약 1 / 예약 2 독립 설정**:
  - 각 예약 박스별로 체크박스를 켜거나 꺼서 독립적으로 활성화할 수 있습니다.
  - 예시 활용법:
    - **예약 1 (주간/퇴근 전)**: `12:30` -> `🌙 절전 모드 (Sleep)` 또는 `🖥️ 화면 끄기`
    - **예약 2 (심야 시간)**: `23:30` -> `🔌 PC 완전 종료 (Shutdown)`
- **예약 시각 (HH:mm)**: 24시간 형식으로 시와 분을 설정합니다.
- **실행 동작 설정**: 각 예약별로 **절전**, **최대 절전**, **화면만 끄기**, **PC 완전 종료**, **다시 시작** 중 원하는 동작을 개별 지정할 수 있습니다.

---

### 🔋 전원 플랜 관리 (Power Plan Switcher)
Windows의 전원 관리 옵션을 1-클릭으로 원터치 전환할 수 있는 관리 도구입니다.

- **목록 조회**: 현재 PC에 등록되어 있는 전원 플랜 목록과 사용 중인 활성 플랜(`[현재 사용 중]`)을 보여줍니다.
- **빠른 전환 버튼**:
  - `🍃 절전 모드 전환`: CPU 클럭과 전력 소비를 최대로 낮춤
  - `⚖️ 균형 조정 전환`: 시스템 부하에 따라 전력 소비 자동 조절 (기본 권장)
  - `🚀 고성능 전환`: 최고의 게이밍 및 작업 성능을 위해 최고 클럭 유지

---

### 💡 빠른 실행 & 카페인 모드

좌측 사이드바 하단의 **💡 빠른 실행** 영역에서 자주 쓰는 기능을 즉시 제어할 수 있습니다.

- **🖥️ 즉시 화면 끄기**: 타이머 없이 누르는 즉시 모니터 전원이 꺼집니다. (마우스를 움직이거나 키보드를 누르면 모니터가 다시 켜집니다)
- **🌙 즉시 절전 모드**: 누르는 즉시 시스템이 절전 상태로 들어갑니다.
- **☕ 카페인 모드 (Keep Awake)**:
  - 대용량 파일 다운로드, 렌더링, 인코딩, 발표 도중 PC가 자동으로 절전 모드로 진입하거나 모니터가 꺼지는 것을 강제로 방지합니다.
  - 버튼을 누르면 `ON` / `OFF`로 토글됩니다.

## 4. 웹 대시보드 & 전력 절감 계산기 활용법

`index.html` 파일을 열어 사용할 수 있는 대시보드 기능 안내입니다.

- **📊 대시보드 개요**: 절전 시간 권장안 및 대기 전력 차단을 통한 탄소 배출 절감량(CO2) 수치를 시각적으로 확인합니다.
- **💡 전력 절감 계산기**:
  - 내 PC의 평균 소비전력(Watt, 예: 사무용 80W, 게이밍 PC 250W)과 하루 방치 시간, kWh 당 전기요금 단가를 입력하면 **월간/연간 예상 절약 금액(원)**이 즉시 계산됩니다.
- **💻 명령어 매니저**:
  - PowerShell이나 CMD 창에 직접 복사해서 쓸 수 있는 유용한 전원 관리 명령어가 정리되어 있으며, `복사` 버튼으로 클립보드에 원터치 복사됩니다.

## 5. 자주 묻는 질문 (FAQ) & 팁

> **Q1. 화면만 끄기(Screen Off)와 절전 모드(Sleep)의 차이점은 무엇인가요?**  
> - **화면 끄기**: 본체(CPU, RAM, 네트워크)는 계속 작동하므로 음악 재생이나 대용량 파일 다운로드가 중단되지 않습니다. 모니터 전원만 차단하여 전력을 아낍니다.  
> - **절전 모드**: CPU 및 본체 작동이 최소 저전력 대기 상태로 전환되며, 다운로드나 작업이 일시 정지됩니다.

> **Q2. 절전 모드 진입 후 다시 켜려면 어떻게 하나요?**  
> - 키보드 아무 키(Spacebar 등)를 누르거나 마우스를 클릭하면 1~2초 만에 기존 작업 상태 그대로 켜집니다.

> **Q3. 프로그램 실행 시 파워쉘 보안 경고 창이 뜨면 어떻게 하나요?**  
> - `Run_PowerSaver.bat` 파일으로 실행하시면 보안 정책 우회 옵션이 적용되어 경고 없이 안전하게 실행됩니다.
