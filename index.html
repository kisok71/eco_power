🖥️ 화면 즉시 끄기 (PowerShell Win32 API)

본체 작업(다운로드/음악)은 유지한 채 모니터만 즉시 전원 OFF 합니다.

(Add-Type '[DllImport("user32.dll")]public static extern int SendMessage(int h,int m,int w,int l);' -Name a -PassThru)::SendMessage(-1,0x0112,0xF170,2)

🌙 30분 후 자동 절전 (CMD 명령어)

30분(1800초) 대기 후 절전 모드를 실행합니다.

timeout /t 1800 /nobreak && rundll32.exe powrprof.dll,SetSuspendState 0,1,0

🔌 1시간 후 안전 완전 종료

60분 후 모든 앱을 정리하고 안전하게 PC를 종료합니다.

shutdown /s /t 3600 /c "PowerSaver 타이머 종료"

❌ 예약된 종료 명령어 취소

지정된 `shutdown` 예약을 즉시 취소합니다.

shutdown /a
